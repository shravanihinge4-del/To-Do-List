📝 To-Do List – Python Project

📌 Project Introduction

The To-Do List is a simple Python project designed to help users manage their daily tasks easily.

This project allows users to add, view, and delete tasks through a simple menu-driven interface.

🚀 Features

- ➕ Add new tasks
- 👀 View all tasks
- 🗑️ Delete tasks
- 🚪 Exit the program
- 💻 Simple and user-friendly interface

🛠️ Technologies Used

- Python
- Lists
- Loops
- Conditional Statements
- User Input

⚙️ How It Works

When the program starts, it displays a menu:

1. Add Task
2. View Tasks
3. Delete Task
4. Exit

The user can select an option and manage their tasks accordingly.
